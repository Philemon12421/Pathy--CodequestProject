## ✨ About Pathy

Pathy is a modern mobility platform designed to make travel smarter, safer, and more connected.

Whether you're commuting, exploring new destinations, cycling, hiking, or driving, Pathy helps you:

* 📍 Record travel routes
* 🗺️ Discover community-shared journeys
* 🚨 Report incidents and hazards
* 🤖 Get AI-powered travel assistance
* 🎵 Listen to music while traveling
* 📊 Track personal travel analytics
* 🏆 Compete on leaderboards
* 👥 Connect with fellow travelers

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/yourusername/pathy.git
cd pathy
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npx expo start
```

### Run Android

```bash
npx expo run:android
```

### Run Web

```bash
npx expo start --web
```
